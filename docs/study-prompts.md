# 用 AI 学习课程

主页右上角“学习提示词”提供六种可复制任务，可选择课程后连同课程目录、学期与教师信息一起复制。AI 需要能够访问或读取该课程文件夹，复制提示词本身不会把资料上传给 AI。

每门课程同步时生成：

| 文件 | 用途 |
| --- | --- |
| `AGENTS.md` | 长期学习约定：阅读顺序、来源含义、证据规则、字幕检索重点与产出方式 |
| `CLAUDE.md` | 引导 Claude 阅读同一份 `AGENTS.md` |
| `README.md` | 课程材料的入口、来源与同步状态 |
| `SCHEMA.md` | 完整课程目录说明，单独复制课程文件夹也可用 |
| `PROMPTS.md` | 可复制的学习任务 |
| `notes/` | 学生与 Agent 自己的指南、证据表、复习计划和笔记，按需创建 |

六种任务的正文维护在 [课程学习指南](../sss/study_resources/course-guide.md)、[字幕考核与安排](../sss/study_resources/assessment-scan.md)、[考前复习](../sss/study_resources/exam-plan.md)、[作业与实验](../sss/study_resources/assignment-lab.md)、[知识点辅导](../sss/study_resources/chapter-tutor.md)、[同步后的学习更新](../sss/study_resources/study-update.md)。复制版还会附上统一的证据要求和课程上下文。

这套模板提炼的是“从选课评价整理课程行动指南”的方法，不把任何个人指南中的学期特定结论固化为通用事实。教材章节、考试范围、评分占比、签到与实验安排必须回到本学期本班材料核实；往届同教师评价和其他教师经验分开列出。

字幕重点覆盖：考试、成绩、分数、实验、各种安排、考试重点、签到、考试范围、考试提示、考试技巧、作业注意点、出勤及近义说法。要求给文件与时间戳、读上下文、辨别更正和否定、保留冲突与未知，不能只做关键词摘抄。

生成文件由同步器维护；已有手写同名文件会保留。个人补充写到 `notes/学习偏好.md`，供 Agent 在每次学习前参考。已有课程在下次同步时补齐这些入口，资料内容不需要重新下载。
